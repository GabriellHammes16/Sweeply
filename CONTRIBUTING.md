# Contribuir

Instale os pré-requisitos do README e execute as verificações antes de enviar alterações. Use fixtures isoladas para testes de limpeza. Nunca rode testes destrutivos sobre temporários, documentos, downloads ou pastas reais do sistema.

Mudanças em comandos Rust precisam validar entradas no backend, atualizar os contratos TypeScript e testar resultados de erro. Não introduza shell genérico, limpeza do Registro, otimizações de RAM, coleta de telemetria ou remoções automáticas.

Componentes devem funcionar em ambos os temas com teclado e movimento reduzido. Preserve PT-BR e texto que explique ações e limites. Novas operações destrutivas precisam de análise, revisão, confirmação e relatório separado.

Não publique arquivos pessoais, logs, screenshots com dados privados, tokens ou referências de terceiros sem autorização. A licença MIT cobre o código original; Inter e Lucide conservam suas licenças próprias.
